# APEXWOLT B2B — backend-этап (план)

Фронт сейчас статический (HTML/CSS/JS в `dist/`), без сервера. Ниже — функции, которые требуют backend, и как они связаны. Реализация — отдельным согласованным этапом.

## 1. «Брошенная корзина» / авторассылка

Цель: если клиент собрал заявку (корзину), но не отправил менеджеру — напомнить письмом «вы не завершили заявку».

Что нужно:
1. **Сбор email + согласие на рассылку** — вход в кабинет или email в форме заявки + галочка opt-in (152-ФЗ; у нас есть `dist/marketing-consent.html` — связать).
2. **Backend** — хранит незавершённую заявку (позиции + email + время) и расписание напоминаний.
3. **Почтовый сервис (ESP)** — реально отправляет письма (транзакционные/маркетинговые).
4. **Триггеры**: заявка собрана, но не отправлена → напоминание через ~2 часа и ~24 часа.

B2B-вариант (возможно сильнее авто-письма): незавершённая заявка падает менеджеру как «тёплый лид» — он связывается лично.

Задел на фронте уже сейчас (дёшево, без backend):
- **Persistence корзины** заявки в `localStorage` (ключ `apexwolt-cart` уже используется в account.js) — вернулся через день, позиции на месте. [статус: частично есть, проверить сохранение из каталога]
- Сбор email + согласие в форме заявки, складывать как лид-черновик.

## 2. Реальный поиск организации по ИНН

Сейчас в кабинете (раздел «Моя организация» → «Реквизиты») кнопка «Найти организацию» — заглушка (`data-demo-action`). Нужен backend-прокси к DaData/ФНС для автозаполнения реквизитов по ИНН. Токены сервиса — только на сервере, не в коде/Git.

## 3. Автоматизация каталога из Excel (главная цель проекта)

Менеджер заполняет Excel (SKU, категория, название, описание, характеристики, остаток, срок, публичная/закрытая цена, ссылка на фото, статус). Детерминированный Node.js-импортёр: парс Excel → валидация → конвейер фото (`rembg` удаление фона + `sharp` ресайз/вебп) → генерация `categoryData` → публикация. ИИ (Claude Haiku) — только тексты описаний/QA. Обязательны dry-run, авто-бэкап и откат. Потом — переезд на Yandex Cloud; N8N опционально как оркестратор.

## 4. Отправка заявки менеджеру и уведомления

Форма заявки сейчас — демо (toast). Нужен backend: приём заявки → письмо/уведомление менеджеру + клиенту, хранение истории в кабинете (разделы «Заявки и заказы», «Документы»).
