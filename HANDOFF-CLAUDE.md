### Последнее решение по открытым и закрытым данным

Пользователь отдельно уточнил: **нельзя замазывать всю коммерческую часть**.

Публично, без авторизации, должны быть видны:

- фотография;
- название;
- артикул;
- характеристики;
- статус наличия/поставки;
- МРЦ;
- строка «Средняя цена на МП» (пока значение `Нет данных`, пока клиент не предоставил цифры).

Только после авторизации должны открываться:

- персональная цена партнёра;
- маржинальность и другие индивидуальные договорные условия.

В `dist/catalog.js` и `dist/collections.js` это уже частично исправлено: МРЦ публична, цена партнёра и маржинальность остаются за auth-gate. Не возвращать сплошное размытие. Помнить, что это пока визуальный прототип: при появлении backend закрытые значения вообще нельзя отдавать неавторизованному клиенту.

### Фотографии крупных направлений

Пользователь выбрал фотографии, а не абстрактные иконки: так интерфейс должен считываться максимально быстро и быть понятным без объяснений.

Единый арт-дирекшен для восьми изображений:

- реальный предметный образ на чистом белом/очень светлом фоне;
- один главный объект либо компактная композиция максимум из 2–3 объектов;
- одинаковый ракурс 3/4, одинаковый масштаб, поля и мягкая контактная тень;
- чёрно-бело-серая палитра инструментов APEXWOLT, аккуратный фирменный синий только как небольшой акцент;
- без людей, интерьеров, текста, цен, декоративного мусора и чужих логотипов;
- изображение не должно выдавать несуществующую конкретную модель за товар из ассортимента;
- для категорий с реальным клиентским фото использовать именно его и аккуратно удалить фон, сохранив форму, цвет, маркировку и комплектность;
- если реального фото нет, использовать фирменную APEXWOLT-заглушку до согласованной генерации, а не случайный товар конкурента.

Рекомендуемые сюжеты:

- аккумуляторный инструмент — дрель-шуруповёрт и аккумулятор;
- сетевой электроинструмент — УШМ с аккуратно уложенным фрагментом кабеля;
- строительное оборудование — строительный миксер/вибратор как компактная предметная композиция;
- измерительный инструмент — лазерный уровень;
- АКБ и зарядные устройства — аккумулятор рядом с зарядной базой;
- сварочное оборудование — сварочный аппарат и аккуратно свернутый кабель;
- садовая и уборочная техника — воздуходувка, без выдуманного сложного окружения;
- электрогенераторы — бензогенератор в предметной съёмке.

Не генерировать сразу восемь финальных изображений без показа направления пользователю. Сначала сделать один пилотный визуал и/или коллаж-превью стиля, согласовать его, затем выдержать остальные семь в точно той же системе.

## 1. Что это за проект

APEXWOLT B2B — премиальная B2B-платформа для корпоративного выбора инструмента, формирования заявки и дальнейшей работы с закреплённым менеджером. Это не интернет-магазин с оплатой на сайте.

Основное направление дизайна:

- белая композиция с большим количеством воздуха;
- мягкие glass-панели;
- один акцентный синий цвет;
- локальный шрифт Golos Text;
- минималистичные линейные SVG-иконки;
- фоновый ролик с покадровым управлением от скролла;
- визуальная подача уровня Apple, но не буквальное копирование.

## 4. Критическая логика фонового видео

В `dist/script.js` сейчас задана шкала:

```js
const sectionFilmStops = [
  { selector: '.hero', time: .08 },
  { selector: '#catalog', time: 3.08 },
  { selector: '.service-intro', time: 6.16 },
  { selector: '.partner-support', time: 9.20 },
  { selector: '#platform', time: 12.24 },
  { selector: '.video-reviews', time: 17.28 },
  { selector: '#account', time: 20.10 },
  { selector: '#contacts', time: 20.10 }
];
```

Намерение пользователя:

- на самих разделах ролик должен быть близок к резкому статичному ключевому кадру;
- в пространстве между разделами анимация плавно проигрывается скроллом;
- каталог держит второй ключевой кадр;
- следующий сервисный раздел — третий;
- следующие разделы последовательно сдвинуты дальше по ролику;
- переходы нельзя телепортировать;
- категории каталога на главной остаются статичными картинками и ведут на отдельную страницу;
- на mobile эффект сохраняется, но используется облегчённый файл и минимум тяжёлых фильтров.

В локальном preview есть Blob-fallback для серверов без корректного HTTP Range. Не удалять его без полноценной замены.

После любых изменений проверить:

1. хиро резкий после загрузки;
2. кадр каталога не перескакивает вперёд;
3. ролик следует скроллу в обе стороны;
4. нет белых разрывов;
5. mobile не загружает desktop-файл;
6. `prefers-reduced-motion` не ломает страницу.

## 6. Известные продуктовые решения

- Категории остаются на главной, но открываются отдельной страницей каталога.
- На главной четыре категории в строке на широком desktop, если ширина позволяет; адаптив не должен сжимать карточки до нечитаемости.
- Поисковик категорий должен быть заметным, но с мягким размытым синим свечением без чёткой границы.
- Избранное, сравнение и профиль — компактные иконки возле заявки.
- Стекло должно быть мягким и дозированным: видео и товар должны оставаться видны.
- Производство — крупный акцент; остальные преимущества партнёров — более компактные плитки.
- Блок видеообзоров остаётся, но пока без нового сгенерированного фонового видео.
- Рассылка планируется, поэтому заготовку не удалять; рекламное согласие должно быть отдельным.
- Контакт разработчика: LMH Studio, Telegram `https://t.me/aleks1y_m`.
