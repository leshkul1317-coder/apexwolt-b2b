# Как править сайт APEXWOLT B2B с телефона (через ChatGPT) — инструкция для вахты

Короткая памятка: как вносить правки, когда под рукой только телефон и нет доступа к компьютеру.

---

## Главное, что нужно знать

- **Код проекта лежит на GitHub:** `https://github.com/leshkul1317-coder/apexwolt-b2b` (приватный).
- **Рабочая ветка:** `work/apexwolt-ui` — правим всегда её.
- **Боевой сайт:** `https://apexwolt-b2b-preview.netlify.app`
- **Авто-деплой:** после того как репозиторий привязан к Netlify, **каждый коммит в `work/apexwolt-ui` автоматически обновляет сайт** (примерно за 1–2 минуты). Ничего вручную деплоить не нужно.

> ⚠️ Правим только **GitHub-репозиторий `apexwolt-b2b`**. НЕ старое ChatGPT-хранилище (`git.chatgpt-team.site`) — там устаревшая версия без наших доработок.

---

## Способ 1 (основной): правки через ChatGPT

1. Открой ChatGPT на телефоне. Убедись, что он работает именно с GitHub-репозиторием **`leshkul1317-coder/apexwolt-b2b`**, ветка **`work/apexwolt-ui`** (подключить GitHub → выбрать этот репозиторий).
2. **Опиши правку максимально конкретно:**
   - какая страница (например: каталог / заявка / главная / FAQ),
   - что именно поменять (текст, цвет, отступ, поведение),
   - как должно стать.
   > Пример: «На странице заявки (`dist/zayavka.html`) кнопка „Оформить заявку“ — сделай её чуть выше, минимальная высота 54px.»
3. Попроси ChatGPT **внести изменение и закоммитить/запушить в ветку `work/apexwolt-ui`**.
4. Подожди 1–2 минуты и **проверь сайт** на телефоне (обнови страницу, см. раздел «Кэш» ниже).

## Способ 2 (для мелочей): правка прямо в GitHub

Для простых текстовых/CSS-правок:
1. Открой файл в репозитории на `github.com` (или набери `github.dev` — это редактор прямо в браузере).
2. Нажми карандаш **Edit** → внеси правку → **Commit changes** в ветку `work/apexwolt-ui`.
3. Netlify задеплоит сам.

## Где что лежит (карта проекта)

Всё, что видно на сайте — в папке **`dist/`**:

| Файл | За что отвечает |
|---|---|
| `dist/index.html` + `script.js` | Главная страница, скролл-видео, лоадер |
| `dist/catalog.html` + `catalog.js` | Каталог, карточки, модалка товара, визард |
| `dist/catalog.data.js` | **Данные каталога** (товары, цены) — генерируются из Excel, вручную лучше не править |
| `dist/zayavka.html` + `zayavka.js` + `zayavka.css` | Страница оформления заявки |
| `dist/zakaz-po-spisku.html/.js/.css` | Заказ по списку артикулов |
| `dist/faq.html` + `faq.css` | Частые вопросы |
| `dist/wizard.js` + `wizard.css` | Визард «Подобрать под задачу» (иконки — в объекте `ic` в начале `wizard.js`) |
| `dist/collections.js` | Избранное и сравнение |
| `dist/kp.js` | Коммерческое предложение (Excel/PDF) |
| `dist/catalog-page.css`, `dist/styles.css` | Стили |
| `backend/` | Серверная часть (заявки, подписки) — пока заглушки |

## Важные правила (передай их ChatGPT, чтобы не сломал сайт)

1. **Проект без фреймворка и сборки** — чистый HTML/CSS/JS в `dist/`. Не мигрировать на React/Vue.
2. **Кэш — обязательно!** Если правишь `.css` или `.js`, в HTML нужно поднять версию в ссылке: `styles.css?v=3` → `?v=4`, `catalog.js?v=24` → `?v=25` и т.д. Иначе у посетителей останется старая версия из кэша.
3. **Не ломать скролл-видео.** Файлы `index.html`, `script.js`, `scroll-film.css` — деликатные; после правок проверять десктоп и мобайл.
4. **Секреты не коммитить** — токены, пароли, матрицу с себестоимостью, персональные данные. Они уже в `.gitignore`.
5. **Никаких онлайн-оплат** — это B2B-витрина и сбор заявки менеджеру.
6. Сохранять стиль: белый премиум, минимализм, мягкое стекло, синий акцент. Иконки — inline SVG, не emoji.
7. В репозитории есть `CLAUDE.md` и `HANDOFF-CLAUDE.md` — там подробные правила проекта; можно дать их ChatGPT для контекста.

## Кэш (если правка «не видна» на телефоне)

Браузер может показывать старую версию. Проверка:
- Закрой и открой вкладку заново, либо открой сайт в **режиме инкогнито**.
- Если правили CSS/JS — убедись, что подняли `?v=` (п.2 выше).

## Чек-лист перед тем, как просить ChatGPT закоммитить

- [ ] Правка описана конкретно (страница + что меняем).
- [ ] Если трогали `.css`/`.js` — попросил поднять `?v=` в HTML.
- [ ] Коммит идёт в ветку `work/apexwolt-ui`.
- [ ] После деплоя проверил сайт на телефоне.
